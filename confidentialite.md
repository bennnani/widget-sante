# Règles de confidentialité – Widget Santé

Dernière mise à jour : 22 novembre 2026

  ## Qui utilise cette application

  Widget Santé est un outil personnel utilisé uniquement par son auteur, Ali Rtal Bennani Cheker. Il n'est pas proposé au public.

  ## Données consultées

  Avec l'autorisation explicite de l'utilisateur, le widget lit en lecture seule, via la Google Health API : les données d'activité (pas, calories, minutes actives), les mesures de santé (fréquence cardiaque au repos) et les données de sommeil.

  ## Utilisation des données

  Ces données servent uniquement à les afficher dans un widget sur l'iPhone de l'utilisateur. Elles ne sont ni vendues, ni partagées, ni transmises à un tiers, ni utilisées pour de la publicité ou pour entraîner des modèles d'IA.

  ## Stockage

  Aucun serveur n'est utilisé. Les données transitent directement entre les serveurs de Google et l'iPhone de l'utilisateur. La clé d'accès est stockée dans le trousseau sécurisé de l'iPhone. Aucune donnée de santé n'est conservée en dehors de l'appareil.

  ## Révocation

  L'accès peut être retiré à tout moment depuis la page Sécurité du compte Google (applications tierces ayant accès au compte).

  ## Respect des règles Google

  L'utilisation des informations reçues des API Google respecte le Règlement sur les données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée.
